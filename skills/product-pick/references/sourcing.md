# 取源 · Sourcing

Step 4 的细则。目标是让每个数字都能追溯到「谁说的、什么时候说的、可不可信」。

---

## 一、四级来源

| 等级 | 定义 | 典型 | 可信度 | 覆盖 |
|---|---|---|---|---|
| **A** | 官方规格页、标准认证文件、厂商技术白皮书 | 品牌官网、EN/ISO 认证报告、CE 证书 | 高（但对自家有利） | 低（关键指标常不公布） |
| **B** | 独立第三方实测 | OutdoorGearLab、SectionHiker、BPL、RTINGS、专业实验室 | 高（方法透明） | 中 |
| **C** | 电商页、分销商参数 | 天猫、京东、REI、B&H | 中（多为转引官方） | 高 |
| **D** | 社区与用户实测 | Reddit、8264、磨房、闲鱼、YouTube 个人长测 | 低（无方法）但独特 | 高 |

**取值优先级**：A > B > C > D。

**但要注意一个反常现象**：对虚标重灾区的指标（温标、重量、续航、亮度），**B 的可信度实际高于 A**。这时候 A 只是「厂商声称值」，不是「真值」。所以：

> 官方值与独立实测冲突时，以独立实测为准，但两个值并列呈现，并注明"官方偏乐观，差距 X%"。

---

## 二、什么叫「独立源」

同一个事实，两个来源不算交叉验证的情况：

| 情况 | 算不算 | 原因 |
|---|---|---|
| 京东参数页 + 天猫参数页 | **不算** | 都是厂商提供的同一份数据 |
| 三篇中文评测都引用官网参数 | **不算** | 信息源头只有一个 |
| 一篇测评 + 它的转载 | **不算** | 同源 |
| 官方规格 + OGL 实测 | **算** | 不同主体、不同方法 |
| OGL 实测 + Reddit 用户实测 | **算** | 但两者结论常不同，冲突时要处理 |

判定标准：**两者是否可能独立地犯错**。如果不可能，就不算独立。

---

## 三、冲突处理

三种冲突，三种处理：

### 1. 官方 vs 实测（最常见）

```
温标：官方标 −7℃（A）｜OGL 实测舒适下限 −3℃（B）
```

处理：**取实测值参与计算**，在表里并列两个值，并在盲区清单「有争议」里注明。理由：官方值来自厂商标称，实测来自独立测试，前者有动机偏差。

使用时额外提醒用户：「按 −3℃ 规划，别按 −7℃」。

### 2. 两个实测互相冲突

```
重量：OGL 标 780g ｜ Reddit 用户称实测 815g
```

处理：先查口径差异（是否含收纳袋、是否含压缩袋、尺码是否相同）。**口径不同就不是冲突**，统一口径后取较高可信度的那个。口径确实相同而数值不同 → 取中位数或较大值（保守），并标注分歧。

### 3. 官方与官方冲突

同一品牌不同渠道的规格页数值不一致（常见于新旧版本混卖）。

处理：确认版本号/批次，分别标注。**这本身是重要信息**——说明市面在混卖两个版本，用户可能买到旧版。

## 四、缺失处理

**绝对规则：取不到就写「未知」，不给估算值。**

「未知」要带原因，原因分为五类：

| 原因 | 例 | 对结论的影响 |
|---|---|---|
| 官方未公布 | 该品牌不公布充绒量 | 中：可用蓬松度近似推断，但推断不进表 |
| 评测未覆盖 | 太小众，无第三方实测 | 中：该属性只有 C 级源，权重可能需要下调 |
| 仅海外版有数据 | 国内版改了规格 | 高：可能根本不是同一个产品 |
| 标准不适用 | 无对应认证标准 | 低：改用其他指标 |
| 我方搜索未到饱和 | 还没搜到 | 高：继续搜，不许交付 |

**「未知」的后果**：该产品标为「数据不足」，不参与排名与前沿（因为归一化需要完整数据）。如果某个候选只在 1 个属性上缺失，允许用「该属性取候选池中位数」参与排名，但必须在表里标注「插补值」并把它计入盲区。

> 宁可让一个候选掉出排名，也不要给它一个看起来合理的假数字。假数字会让整张表失去可追溯性。

## 五、价格采集

价格不进得分，但它是前沿横轴，失真会直接毁掉结论。

**必须记录四个字段**：

| 字段 | 例 |
|---|---|
| 数值 | ¥2,499 |
| 渠道 | 天猫官方旗舰店 |
| 日期 | 2026-10-25 |
| 口径 | 到手价（含券后）/ 活动价 / 日常价 / 含税海淘价 |

**口径必须统一**。把「天猫券后价」和「REI 官网价（未含转运和关税）」放进同一张图，前沿就是错的。

海外款的价格要加一行说明：`$349 ≈ ¥2,520 + 转运 ¥180 + 关税约 ¥250`。

**价格波动提醒**：如果某款正在大促，标注「活动价，X 日后可能回升」。这一点对决策影响巨大——用活动价做前沿，会把这款的性价比高估。

## 六、记录格式

对比矩阵的标准写法（存盘 md 用这个）：

| 属性 | A 款 | B 款 | C 款 |
|---|---|---|---|
| 舒适温标（℃） | −5 ᴬ ¹ | −7 ᴬ ¹ | −4 ᴮ ² |
| 总重（g） | 780 ᴬ ¹ | 1050 ᴬ ¹ | 620 ᴮ ² |
| 蓬松度（FP） | 800 ᴬ ¹ | 850 ᴬ ¹ | 750 ᴬ ¹ |
| 压缩体积（L） | 8.2 ᴬ ¹ | 9.5 ᴬ ¹ | 6.8 ᴮ ² |
| 价格 | ¥2,499 ³ | ¥1,899 ³ | ¥1,299 ³ |

脚注：

1. 品牌官网规格页，2026-10-20 抓取
2. OutdoorGearLab 实测，2026-08
3. 天猫官方旗舰店到手价，2026-10-25

上标写等级，脚注写来源与日期。**每个值都必须有上标**，没有上标的数字不许出现。

## 七、可信度自检（交付前跑一遍）

逐条打勾，未通过的不许交付：

- [ ] 每个数值都有来源等级和日期
- [ ] 每个关键属性至少有 1 个 A 或 B 级源
- [ ] 每个候选至少有 2 个**真正独立**的源
- [ ] 所有冲突都已并列呈现，没有偷偷取一个值
- [ ] 所有缺失都写了「未知」+ 原因，没有一处估算
- [ ] 价格口径统一，海外款标注了额外成本
- [ ] 价格带了抓取日期
- [ ] 没有任何「一般来说」「通常」「大概」作为数值依据

---

## 八、虚标识别清单

遇到这些信号，必须再找一轮独立源：

| 信号 | 含义 |
|---|---|
| 官方参数是整数且异常好看（续航正好 30h、重量正好 500g） | 可能是目标值而非实测值 |
| 商品页写「符合 XX 标准」但无证书编号 | 未经认证 |
| 只标「极限温标」不标「舒适温标」 | 在回避可比较的指标 |
| 重量标注带「约」「起」 | 大概率不含配件或是最小码 |
| 同一型号在不同渠道参数不一致 | 版本混卖或参数造假 |
| 全网只有官方通稿，无任何独立评测 | 可能是新品或贴牌 |
| 二手市场大量低价抛售 | 不好用的强信号 |
| 差评集中在同一个具体问题 | 真实设计缺陷，不是个体差异 |

## 九、不确定度赋值（最坏情况检验的输入）

`--worst` 要每个产品一个 σ。赋值规则：**看该产品关键属性里最差的那个来源等级**，不是看最好的。

| 最低来源 | σ | 判定标准 |
|---|---|---|
| A | 0–3% | 有官方规格 + 标准认证，且至少一个独立实测能印证 |
| B | 3–8% | 官方没给关键值，但专业实测覆盖了 |
| C | 8–15% | 只有电商页，无任何独立评测 |
| D | 15–25% | 只有社区信息，无官方或媒体报道 |

### 四类加码（在基准上再加 5%）

1. **落在虚标重灾区**：温标、重量、续航、亮度——这四项的官方值本身就是乐观值，不是误差
2. **混卖版本**：同一型号有多个版本在售（亚洲版/欧美版、新款旧款同时在架）
3. **新品无长测**：上市不足 6 个月，耐久性完全未知
4. **仅海外数据**：国内版改了规格，但参数表沿用海外版

### 三条纪律

- **不要给所有产品同一个 σ**。相同 σ 不改变排名，等于白跑一遍。
- **不要为了显得精确写 0.073 这种数**。用 5%、10%、15% 这种量级就够，它的作用是区分档位，不是估误差。
- **σ 超过 25% 就不该参与排名**，直接把这个产品按「数据不足」剔除（见第四节），而不是带着巨大的不确定性去算分。

### 为什么这件事值得做

它不是精确的误差估计，是一个**把数据质量差异显性化的装置**。文档里写「B 款参数来自电商页」没人会当回事；但写成「B 款最坏情况会掉两名」，就会有人去核一下。这才是它的作用。

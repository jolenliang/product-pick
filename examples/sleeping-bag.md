# 示例：一次完整的睡袋选型

> 这是 `product-pick` 的**真实运行存档**，未经修饰。选它作示例是因为这次跑出了一个很典型的教训——一个数据口径错误差点把「实质等价」变成「A 完胜 B」。
>
> 读的时候可以注意四件事：
> 1. **权重核对闸门**怎么在没看到任何数据之前，把「总重占 41%」这件事摆到用户面前（第 0 节末）
> 2. **完整评分表**如何让两款的差距一眼定位到单独一项（第 3 节）
> 3. **稳健性检验**如何把「A 比 B 高 0.84 分」翻译成「这两个其实是一回事」（第 4 节）
> 4. **盲区三类**怎么诚实标出「这次决策建在多少不确定之上」（第 6 节）
>
> 存档结构 = Step 7 的交付物结构。三个月后回看时，你需要知道当时基于什么信息、做了什么假设。

## 0. 决策档案（可复现的最小信息集）

| 项 | 内容 |
|---|---|
| 要解决的问题 | 换掉现有睡袋。主诉：太重；最怕：淋湿后羽绒结块、失温 |
| 使用场景 | 川西高海拔徒步，三季到初冬 |
| 硬门槛 | 舒适温标 ≤ **-8℃**（原为 -10℃，为换取真减重主动下调）；羽绒填充；适配 181cm |
| 锁定风险（用户自选） | 面料不能两年就废 → 7D 出局 |
| 价格处理 | **不进得分**，只做展示与前沿分析 |
| 权重来源 | 用户现拍一轮序数排序 + ROC 换算（Barron & Barrett 1996） |
| 候选池 | 7 款（3 国产 + 4 海外），从 20+ 款初筛 |
| 数据截止 | 2026-10-25 |

### 权重（ROC 换算结果）

用户排序：总重 > 舒适温标 > 绒质指数 > 蓬松度 > 面料丹尼尔 > 压缩体积

```
按你的排序换算出来是：

  总重        40.8%   ← 四成话语权
  舒适温标    24.2%   ← 四分之一
  绒质指数    15.8%
  蓬松度      10.3%
  面料丹尼尔   6.1%
  压缩体积     2.8%   ← 基本不影响排名
```

**闸门体检结论**（三项，逐项报给用户）：

| 体检项 | 本次结论 |
|---|---|
| 榜首是否过高 | 40.8%（n=6）。这是六选一排序的数学后果，不是偏好。已明确告知，用户接受 |
| 末位是否无意义 | 压缩体积仅 2.8%，不可能独力翻转排名。保留理由：它是唯一与「收纳体积」相关的物理量，且本次恰好是前两名的唯一差异项（见第 4 节） |
| **门槛是否混进加权项** | **有两项被挪走了**：<br>① 「是否羽绒」原被当作属性，改为硬门槛（非羽绒直接出局）<br>② 「充绒量」原在加权项，因 Montbell 官方不公布导致整列数据缺失，改为展示列并重算权重 |

用户确认「认」，权重落锁。

| 属性 | 方向 | 权重 |
|---|---|---|
| 总重 | 越小越好 | 40.8% |
| 舒适温标 | 越小越好 | 24.2% |
| 绒质指数 | 越大越好 | 15.8% |
| 蓬松度 | 越大越好 | 10.3% |
| 面料丹尼尔 | 越小越好 | 6.1% |
| 压缩体积 | 越小越好 | 2.8% |

### 属性定义（避免复现时口径漂移）

- **绒质指数**（自定义复合指标，满分 100）：鹅绒 + 绒子含量 ≥90% = 100；鹅绒但绒子含量未标注（按行业常见值估值）= 93–97；鸭绒 = 85 起。
  **注意：海外款用 fill power（FP）体系，不标绒子含量；这两者不是同一指标**，800FP 鹅绒大致对应绒子含量 90% 左右，故海外款取值均为**估值**，非官方数据。
- **充绒量已移出打分**：Montbell 官方不公布充绒量，若保留会造成单款数据缺失导致整列失效。改为展示列。

## 4. 稳健性警告：这两款实质等价

### 关键证据：剔除不可比项后完全同分

黑冰 Z700 与天石极光 LIGHT 700 的五项核心数据**逐项相同**：990g / -9℃ / 绒质 100 / 800FP / 10D。

唯一差异是压缩体积，而这恰恰是**口径不可比**的一项（黑冰给压缩后体积，天石给收纳袋容积推算值）。把这一项整体剔除、权重按比例分摊给其他五项后重算：

| 名次 | 产品 | 得分 | 价格 |
|---|---|---|---|
| 1 | 黑冰 Z700 | **72.81** | ¥2,479 |
| 2 | 天石极光 LIGHT 700 | **72.81** | ¥2,000 |

**完全同分。** 此前出现的 2.76 分差距（天石 70.81）完全来自一处口径错误：我曾把天石「外袋尺寸 20×40cm」推算出的 12.6L 当作压缩后体积，而黑冰的 6.0L 是压缩后实测值——两个不同口径的数直接比，凭空给天石扣了 2.76 分。

> 这是整个流程里最值得记住的教训：**归一化矩阵对口径错误毫无免疫力，它会安静地把错误算成一个看起来正常的分数差。** 分差小的时候，先怀疑数据，再怀疑权重。

### 权重敏感性（换赢家所需的最小权重变动）

| 挑战者 | 关键属性 | 该权重需变为原值 | 即 | 当前分差 |
|---|---|---|---|---|
| Parsec 0 | 总重 | 0.31× | -69% | 12.46 |
| Phantom 0 | 总重 | 0.25× | -75% | 21.17 |
| Cumulus Spotter 600 | 蓬松度 | 5.82× | +482% | 25.53 |
| WM Kodiak | 舒适温标 | 4.46× | +346% | 45.93 |

**结论稳健。** 最敏感的一条也要把「总重」权重砍掉 69% 才会翻盘——这意味着你必须从「重量绝对第一」变成「重量只算第四」，那不是微调，是换了一套价值观。

**但稳健 ≠ 分出了高下。** 前两名的排序只由压缩体积和价格决定，而压缩体积不可比、价格不进得分。所以：

> **别在 Z700 和极光 LIGHT 之间反复纠结。它们不是两个选项，是一个选项的两种包装。用次级标准决定：官方渠道可验真 / 售后与补绒服务 / 现货与发货速度 / 尺码库存。**

### 我的次级标准取舍：倾向天石

| 次级标准 | 天石极光 LIGHT 700 | 黑冰 Z700 | 判断 |
|---|---|---|---|
| 假货风险 | 低 | **高（系统性）** | **天石胜** |
| 价格 | ¥2,000 | ¥2,479 | 天石胜 |
| 售后/补绒网点 | 待查 | 国内较成熟 | 黑冰略胜 |
| 品牌二手残值 | 一般 | 较高 | 黑冰略胜 |

**黑冰假货为什么算系统性风险**：官方实拆假 G400，实测绒子含量仅 **1.3%**（正品 88.6%）；更麻烦的是防伪码**不绑定具体产品**——扫码显示「正品」不代表你手上这只就是正品。这不是「小心点就行」，这是验证手段本身失效。对一只标称 -9℃ 的睡袋，绒子含量 1.3% 意味着它在 0℃ 就会让你失温，直接命中你最怕的那条。

¥479 的差价，买的是「不用赌」。

## 5. 主观项交给你（否决权，不加权）

以下三项**没有进打分**，但任何一项不成立，上面的结论作废：

1. **尺码**。你 181cm，卡在很多品牌的 L 码边界（多为 183cm 上限）。轻量睡袋为减重常做窄身短码。**到手前必须核实具体尺码表的身高上限与肩宽**，而不是看「L」这个字。→ 这是本次最大的未验证项。
2. **版型合不合身**。肩宽、脚部空间、侧睡时膝部是否顶到面料。这一项只能试，看参数没用。
3. **你实际会不会去**。这个睡袋的 -9℃ 舒适温标对应的是川西深秋/初冬和雪线以上。如果未来两年你的主战场其实是夏季 3000m 以下，你买的是过剩配置——**这时不该换睡袋，该保留现有的**。

## 7. 组合方案（已过评分）

第一名的跛脚处：**-9℃ 是厂标，无第三方认证**。这意味着它可能只到 -6℃。下面三个组合应对这个问题，按性价比排序。

### 方案 A：天石极光 LIGHT 700 + 羽绒内胆（**推荐**）

| 项 | 数值 |
|---|---|
| 成本 | ¥2,000 + 约 ¥400 = **¥2,400** |
| 增重 | 约 +150–200g（合计约 1150g） |
| 等效温标 | 约 -15℃ |
| 评分逻辑 | ¥400 买约 6–8℃ 温标。对比 Parsec 0 花 ¥2,320 只买 1℃ 温标 + 110g 减重，**内胆方案的边际效率高一个数量级** |

**为什么这是最优解**：它同时解决了「厂标不可信」和「极端天气」两个问题，且总价仍低于最便宜的海外款（Montbell ¥3,400）。内胆只在硬仗时带，日常徒步仍是 990g。

### 方案 B：只买天石，现有睡袋留作夏季/备用

| 项 | 数值 |
|---|---|
| 成本 | ¥2,000 |
| 适用 | 三季川西，最低到 -5℃ 左右 |
| 评分逻辑 | 最简单、最便宜。风险是遇到 -10℃ 寒潮无解 |

### 方案 C：改问题——睡袋不动，换睡垫（**必读**）

你说过「背部总是发凉发潮」。**这是睡垫 R 值不足的典型信号，不是睡袋的问题。**

睡袋的羽绒在你身下被体重压扁，几乎不提供隔热；背部保暖几乎全部由睡垫的 R 值决定。换一只 -9℃ 的睡袋，背部依然冷——因为冷是从地面传导上来的。

| 项 | 数值 |
|---|---|
| 成本 | R 值 4.5 左右的充气垫约 ¥800–1,500 |
| 效果 | 直接解决主诉中的「背部冷」 |
| 前置 | **你已确认有睡垫，但未告知 R 值** |

> 如果你的睡垫 R 值 < 4，方案 C 的优先级高于 A 和 B。先花 ¥1,000 换睡垫，背部问题可能直接消失，睡袋可以继续用现有那只。

### 已评估但否决

- **等待下一代**：这个品类没有「三个月内有针对性改款」的信号，不适用。
- **买二手**：羽绒睡袋二手最大的问题是无法验证绒子含量衰减与清洗史，恰好是本轮最担心的点，否决。
- **拆两件买**（主力 + 极端场景租赁）：川西线路沿途没有睡袋租赁服务，不可行。

## 8. 失败绊网（什么时候该承认选错）

**这些是提前定好的改主意条件，不是事后追责。**

| # | 触发信号 | 说明什么 | 动作 |
|---|---|---|---|
| 1 | **睡垫 R 值 < 4** | 主诉（背部冷）不在睡袋上 | 先换睡垫，睡袋决策暂缓 |
| 2 | 连续两次在 **-5℃ 以下被冻醒** | -9℃ 厂标偏乐观（实际可能只到 -6℃），验证了盲区里的怀疑 | 加内胆（¥400），**不要换袋**（¥4,000）。换袋是沉没成本在驱动 |
| 3 | 到手后压缩后体积明显塞不进 8L 压缩袋 | 压缩体积数据有水分 | 7 天无理由内退换；同步下调该品牌全部数据的可信度 |
| 4 | **一年内使用少于 5 晚** | 不是装备问题，是需求判断错了 | 停止在装备上追加投入，转 `life-decision` 处理「我到底会不会去徒步」 |
| 5 | 到手发现面料在第一次使用后就出现勾丝/钻绒 | 10D 是耐久下限，低于预期 | 触发保修；若反复出现，说明你的使用环境比 10D 更粗暴，下一只必须上 20D 并接受增重 |

## 9. 三个月后复盘时该回答的问题

1. 实际最低使用温度是多少？-9℃ 厂标兑现了几成？
2. 有没有一次是在「睡垫不够」而不是「睡袋不够」的情况下被冻到？
3. 990g 相对原来那只，体感减重明显吗？（如果无感，说明真正压垮你的可能不是睡袋重量）
4. 有没有后悔没买 ¥4,000 那档？如果有，具体是在哪个场景里？
